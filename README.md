# Lluvia de Pixeles - Teclado

Pequeño juego web interactivo hecho con HTML, CSS y JavaScript, sin dependencias externas.

## Cómo jugar

- Presiona cualquier tecla para generar un pixel de color que cae y añadir una letra aleatoria al panel lateral.
- Los pixeles se apilan en columnas. La partida termina cuando una columna alcanza la altura máxima.
- Pulsa **Reiniciar** para comenzar otra partida. El puntaje y los pixeles se reinician, pero las letras acumuladas se conservan.
- Pulsa **Borrar letras** para vaciar el panel de letras.

## Ejecutar localmente

Abre `index.html` en un navegador moderno. No hace falta instalar dependencias ni iniciar un servidor.

## Publicar con GitHub Pages

1. Sube este proyecto a un repositorio de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama principal y la carpeta raíz (`/`), y guarda los cambios.

GitHub Pages publicará el sitio usando `index.html` como página de inicio.
